
# Slotify

Smart Appointment Booking & Scheduling Platform.

## Overview

Slotify helps businesses manage appointments,
services, working hours, and customer bookings.

## Tech Stack

- Next.js
- React
- NestJS
- Node.js
- PostgreSQL
- Prisma ORM
- Redis

## Project Structure

- apps/web: Frontend application
- apps/api: Backend application
- packages/shared: Shared utilities
- docs: Project documentation
